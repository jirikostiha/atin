# Atin API Reference

Welcome to the **Atin** API Reference.

Atin provides strongly-typed parsing, formatting, and rounding operations for alphanumeric time interval notation.

## Namespaces

- **`Atin`**: Core library components including the `AtinParser` static parser, `TimeSpanExtensions` formatting and rounding extensions, and `DateTimeOffsetExtensions` timestamp rounding extensions.
